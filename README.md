# 大数据 · 交互图鉴（液态玻璃版）

> 在线访问：**https://yyypsc-lab.github.io/bigdata-atlas/**

一份可离线打开的大数据基础概念可视化手册：**11 个可动手实验台 + 术语速查 + 掌握度自测**。
界面采用 Liquid Glass 风格：半透明玻璃层、折射高光、浮动胶囊导航、跟随鼠标的镜面光斑。

## 里有什么

| # | 实验台 | 你可以动手做什么 |
|---|---|---|
| 01 | 数据量尺 | 拖动 KB → ZB，实时换算照片 / 电影 / 硬盘数量 |
| 02 | 5V 雷达 | 拖顶点或滑杆，实时判断场景最像哪类系统 |
| 03 | 数据管道 | 拉满流量，定位瓶颈环节与背压 |
| 04 | HDFS 切块 | 改文件 / 块 / 副本，看块数、元数据与机架布局 |
| 05 | WordCount | 分步走完 Split → Map → Shuffle → Reduce |
| 06 | 窗口与水位线 | 滚动 / 滑动 / 会话窗口 + 迟到数据 |
| 07 | CAP 三角 | 拖点 + 切断网络，观察 CP / AP / 假 CAP |
| 08 | 行存 vs 列存 | 选列，对比真实读取字节 |
| 09 | 数据倾斜 | 拉倾斜系数，加盐前后对比 |
| 10 | 架构选型 | 5 个约束 → 推荐栈 + 理由 + 反模式 |
| 11 | 掌握度自测 | 9 题解析 + 主题能力画像 |

## 技术说明

- 单文件 `index.html`，**零外部依赖**：CSS / JS 全部内联，图表由原生 SVG / Canvas / DOM 手绘。
- 无网络请求、无字体下载；断网双击即可打开。
- 进度与答题记录只写入浏览器 `localStorage`（key: `bigdata-atlas.v1`）。
- 明暗双主题（右上角切换）；键盘 `/` 术语、`?` 帮助、`J/K` 上下节、`1–9` 跳转。
- 响应式：390px 手机端重新排版。

## 部署

GitHub Pages（`main` 分支根目录）。更新方式：替换 `index.html` 后提交即可。
